# Pistaklero

Bolsa de empleo con perfil-portfolio, postulación en 1 clic y sistema anti-ghosting.

## Requisitos

- Node.js 24 LTS (`nvm use`)
- pnpm 10

## Scripts

| Comando | Qué hace |
|---|---|
| `pnpm dev` | Servidor de desarrollo |
| `pnpm build` | Build de producción |
| `pnpm start` | Sirve el build |
| `pnpm lint` | ESLint |
